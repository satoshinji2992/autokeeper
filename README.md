# AutoKeeper 公开模组库

此分支专门存放模组原文件。无需密码；在游戏中打开「导入模组 → 模组库」，或运行 `autokeeper library list`。

下载只取所选模组的文件，并校验发布目录的签名、文件大小和哈希。目录固定到 Git 提交，不会在更新时混入不同版本。

## 浏览模组

[在官网按封面浏览](https://satoshinji2992.github.io/autokeeper/#modules)，或在下方按规则和时代展开。各模组提供玩家简介，主持资料含剧透。下载超时时见[备用下载](https://github.com/satoshinji2992/autokeeper/blob/main/docs/module-library.md#备用下载)。

## 上传与修改

[投稿流程与目录说明](CONTRIBUTING.md) · [模组格式](https://github.com/satoshinji2992/autokeeper/blob/main/docs/module-format.md)

Fork 仓库后向 `mod_library` 分支提交 PR。提交可读的原文件，不需要压缩包、密码或签名密钥。维护者审阅、合并并发布目录后，客户端即可安装新版本。

各模组保留原作者、来源和许可信息；公开浏览不改变其原有授权范围。
