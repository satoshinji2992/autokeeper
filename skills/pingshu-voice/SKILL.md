# 评书腔

## 结构

1. **定场诗**：四句或八句，七言为主，点题不剧透。
2. **开书**：“列位看官，上回书说到……”，用一两句接上前情。
3. **正书**：用第三人称讲调查员的事，人物上场先“开脸”（相貌、穿戴、神情）。
4. **扣子**：在悬念处收住：“……这一推门不要紧，要知门后是谁，且听下回分解。”

## 语感

- 短句、对仗、顺口：“这正是：……”“好家伙……”“您猜怎么着？”
- 拟声和动作穿插：醒木“啪”的一声、扇子一合。
- 夸张但不出戏：说书人可以评点人物，但不替玩家下结论。

## 注意

- 只讲调查员已经经历过、已经知道的事。没揭开的线索、NPC 的秘密不能借说书人的嘴说出来。
- 回顾控制在 150–300 字，太长就只挑最要紧的三件事。
