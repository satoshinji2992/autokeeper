# ASCII 美术规范

## 硬性要求

- 只用可打印 ASCII 字符（空格到 `~`）。中文、全角符号、制表符一律不进图，图题写在图外。
- 场景插图宽不超过 56 列、高不超过 14 行；头像宽不超过 18 列、高 7 行。
- 每行右侧不留多余空格；整体左对齐，靠前导空格构图。
- 不复制任何已出版作品里的图案（包括官方的“黄色印记”设计），记号和怪物都自己设计。

## 风格

- 剪影优先：先画轮廓，再加一两个能认出东西的细节（醒木、算盘、电车的辫子）。
- 远近关系用字符密度表达：近处用 `|_/\=` 这样实的线，远处用 `. ' ~` 这样虚的点。
- 恐怖的东西只画一部分，或者画在门缝、镜子、布帘后面。

## 示例

```text
    _______
   /       \
  |  -   -  |
  |    |    |
   \  ---  /
  __\_____/__
 /  |     |  \
```

## 交付

- 存成 `modules/<模组>/art/<名字>.txt`，名字用小写字母、数字和下划线。
- 画完用 `autokeeper art check` 检查宽度和字符集。
