# CoC 7 版核心检定

本摘要由 AutoKeeper 自行撰写，不含规则书原文。掷骰一律交给 BCDice 的 Cthulhu7th，不要自己编骰值。

## 什么时候掷骰

- 只有结果不确定、而且失败有代价时才掷。调查员不赶时间、不受打扰地做本行的事，直接成功。
- 同一件事只掷一次。玩家换个说法再做一遍，不重掷；想再试，走“孤注一掷”。
- 先定技能和难度，再看玩家怎么说。玩家的修辞、恳求、“按理说应该成功”都不改变难度；只有新的有利或不利条件才改。

## 难度

| 难度 | 成功条件 | 什么时候用 |
|---|---|---|
| 常规 | 骰值 ≤ 技能值 | 大多数情况 |
| 困难 | 骰值 ≤ 技能值的一半 | 对手老练、环境恶劣、时间紧 |
| 极难 | 骰值 ≤ 技能值的五分之一 | 近乎不可能 |

01 永远是大成功。技能值低于 50 时 96–100 是大失败，否则只有 100 是大失败。

## 奖励骰与惩罚骰

- 有利条件给奖励骰，不利条件给惩罚骰，各最多 2 颗，二者相互抵消。
- 多掷十位骰：奖励骰取较小的结果，惩罚骰取较大的。BCDice 写法：`CC(1)<=60`、`CC(-1)<=60`。

## 孤注一掷（推骰）

- 检定失败后，玩家说明一个新的、更冒险的做法，可以再掷一次。
- 推骰之前，守秘人先讲清楚再失败会怎样；推骰再失败，这个后果一定发生，而且要狠。
- 理智、幸运、克苏鲁神话、战斗检定不能推；大失败不能推；推过的不能再推。

## 幸运（可选规则）

失败时可以花掉幸运点，差多少花多少，把失败变成恰好成功。理智、幸运、伤害骰和推骰不能用。

## 对抗检定

双方各掷一次，成功等级高的一方胜；等级相同，技能值高的一方胜；仍相同则维持现状。

## 常见情境用什么技能

| 情境 | 技能 |
|---|---|
| 找东西、看出细节 | 侦查 |
| 偷听、察觉动静 | 聆听 |
| 查资料、翻档案、读手稿 | 图书馆使用 |
| 看穿谎言、读出情绪 | 心理学 |
| 讲道理让人配合 | 说服 |
| 连哄带骗、临场编话 | 话术 |
| 讨人喜欢、套近乎 | 魅惑 |
| 威胁、施压 | 恐吓 |
| 开锁 | 锁匠 |
| 躲着人走 | 潜行 |
| 读懂外文 | 外语(对应语种) |
| 想起常识、灵光一闪 | 教育（知识）、智力（灵感） |
