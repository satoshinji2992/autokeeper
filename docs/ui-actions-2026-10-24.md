# 更新入口与角色、房间操作

这批修改调整界面和准备阶段的操作约束，已纳入 0.0.5.7 的发布范围。

- 主页增加“检查更新”。手动查询 GitHub 最新发行版，通过 uv 安装的客户端可确认后更新，保留原可选组件与 Python 版本；源码运行、网页版和其他安装方式提供相应说明及发行页入口。房间运行期间不能执行更新，安装完成后需重新启动程序。
- 角色卡列表增加编辑、删除、复制、导出、新建与返回按钮。模组预设和存档角色保持只读，复制后可以编辑。
- 编辑表单独立滚动，保存与取消按钮固定在右侧；滚到背景、物品或照片时仍可直接保存。
- 联机“开始游戏”改为单独一行的大按钮。准备后锁定当前座位和角色，取消准备后才可更换。服务端同时拒绝换座、观战释放座位、换卡及重新建卡请求；断线和主动离开仍正常释放连接。

验证覆盖 80×24 与 120×40 两种窗口、实际按钮点击、表单滚动、快捷键、真实本地联机请求、更新元数据和安装程序的离线模拟。相关测试 **93 项通过**，Ruff 与差异检查通过。未请求付费模型，也未实际安装更新。

界面预览保存在 `dev/output/ui-actions-2026-10-24/`。导出预览修正了 SVG 对中文字符宽度的计算，不改变游戏的终端绘制。
