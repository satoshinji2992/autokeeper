从早班火车进站开始

AutoKeeper 把《克苏鲁的呼唤》第 7 版的跑团桌面搬进了终端。你扮演调查员，用中文说出想做的事；AI 担任守秘人，铺陈场景、扮演遇到的人，在需要检定时请你掷骰。可以独自调查，带上 AI 同伴，也可以叫朋友凑一桌。

挑好模组和调查员，守秘人会顺着角色背景拉开序幕。以《追书人》为例，早班火车驶入阿诺兹堡，托马斯的家在小镇尽头的公墓旁，走过去还有一段路。你可以向站务员打听方向、找家餐馆吃早饭，或拐进图书馆查查旧报纸。走到原作没写的地方，守秘人会即兴补出人物、地点和支线，保存在这一局里；偏爱原作的话，也能切回严格模式。

需要检定时，桌面会请你亲手掷出物理模拟的十面骰。失败之后要不要花幸运、要不要孤注一掷，由你当场决定。理智、伤势与成长也按规则结算，找到的线索、手稿、见过的人都会留下记录。每回合自动存档，下次接着往下查。

照片、字符与天气

老照片和模组插图会转成彩色字符画，雨雪、雾气与灯影随场景变化。NPC 开口时立绘登场，重要时刻展开整屏大场景。即兴的人物与地点也能配图；本机装有并登录 Codex 时，还可以开启 AI 画图，按剧情变化重绘着火的房屋、受伤的人物。

把你手上的模组拿来跑

仓库自带《追书人》《冬雪之下》和《有些人油盐不进》，装好就能开第一局。想跑自己攒下的任意 CoC 模组，可以导入 PDF、Word、Markdown、文本或 ZIP。AI 会通读原文，整理人物、地点、线索和事件，保留插图与手稿，校验后编译成能直接开团的模组。

uv run autokeeper import 模组.pdf

没有现成剧本，也可以给一句设定。生成器会联网考据、写剧情、配图，生成一本原创模组。导入、读图和游玩可以各选各的模型，不绑死某一家服务。

uv run autokeeper generate "1931 年上海，一张没有标签的唱片" --id changpian

专属规则和一句话家规

疾病蔓延、倒计时、资源消耗或书架机关，可以用规则插件处理。AI 能在编译时编写插件，跑通隔离沙箱中的测试后再加载；开团后按 Ctrl+K，也能用一句话加家规。插件可以挂载状态面板、注册自定义行动，还能出选择、填空、排序和棋盘小游戏。

模组格式规则插件

一个人随时开，或者叫朋友凑一桌

开局可以用模组预设，也能给一句人设，让 AI 协助车卡。输入历史、公众人物的名字时，程序会检索资料和肖像，结合人物经历与模组年代问背景，再按七版规则核算属性和技能点。手上的老卡也能带来：骰娘 .st、表格、PDF、纸质卡照片和酒馆卡都有对应的导入方式。

想约朋友，就由房主在标题页开房间，把网址发过去。朋友用浏览器打开就能车卡入座，不用安装 Python 或配置密钥；模型和存档由房主负责，没坐满的座位可以交给 AI。人齐后各自提交行动，守秘人按顺序往下讲，讲述时也能先输入下一轮的行动。

掉线后重新入座即可继续。支持局域网，也可以通过虚拟局域网异地联机。只是想看故事的话，还有观战模式，让 AI 调查员自己跑完整局。

安装与启动

需要 Python 3.12+、uv 和 Node.js 18+，建议一起装上 chafa 来显示照片字符画。克隆仓库后安装依赖、准备模组，再让 doctor 检查一下环境。

git clone https://github.com/satoshinji2992/autokeeper
cd autokeeper
uv sync --extra claude --extra graphrag
uv run autokeeper setup
uv run autokeeper doctor

选择模型，再启动

支持 Claude、DeepSeek、Codex、Ollama 和兼容接口，也能按职责混搭模型。进入标题页选“新的调查”，挑好模组和调查员，就能开始。

uv run autokeeper

想在浏览器里玩，运行 uv run autokeeper serve。这里是项目展示页，实际游戏和模型运行在你自己的电脑上。

从 0.0.1 升级

升级前请备份 saves/。0.0.2 将数据整理到 data/，自己的调查员、本地模型和知识库会自动迁移，但旧版存档不能继续读取。
