# 开发者模式

游戏内按 **F12**、输入 `/dev`，或从 Esc 菜单选择“开发者模式”进入，再按一次退出。进入后：

- 顶栏变色，标出“开发者模式”；
- 叙述下方出现开发者面板：本轮每次模型调用的分工、模型、用时、输入量与缓存命中，本轮检定，所有人物的实际位置，接下来的日程，当前标记和进行中的幕后任务；
- 第一次进入时打开本机私有网页，里面是完整记录；之后点面板上的“打开完整记录网页”再打开。

开发者模式不会暂停回合、后台世界或导演任务。面板和网页都包含未公开设定，只供运行引擎的本机使用。

## 记录与查看

记录从本局引擎启动时开始，按存档持续写入 `data/games/debug/<slot>.jsonl`，跨读档保留，不受会话压缩、最近 60 次调用或终端显示长度限制。

网页提供当前世界与模组、重要 NPC 的实际位置和计划、活动会话的系统提示与摘要，以及完整的历史调用与任务记录。模型请求在开始时记录输入，随后保存返回片段、重试、格式修复、最终回复、用量和错误。图片任务另存请求、原图引用、结果位置与失败状态；保留提供方实际返回的内容，不推测未返回的思考。

调用与任务按页读取，展开条目即可核对原始数据。分页只限制当前显示数量，不删除历史。“下载完整记录”包含所有页及历次后台快照和排查记录。后台读写失败会在概况中显示。

较早版本未保存的请求无法补回；读档后仍可查看存档中的会话和世界资料，但不能据此声称还原了旧请求或当时的完整上下文。

旧版说书人曾接收全局经历。再次表演时，系统仅隔离带有该旧提示原文的角色会话，将移出的原文保存在诊断记录中；角色实际获得的世界知识不变。若旧内容已压成摘要且不再有可识别标记，系统无法可靠判断污染范围，不会自动清空全部角色记忆。

概况中的一致性巡检会核对人物位置投影、物品持有记录、计划条件、公开信息的来源，以及后台方案的读取版本。报告给出具体 id、等级和依据，仅供排查；受阻计划和过期方案不一定是程序错误。巡检不调用模型，不阻止游戏，也不修改历史。人物有意撒谎、误解和传闻不会因此被强制纠正。

插件结算会分别保存原始输出、骰值、规则效果和后续通知。中断后继续原操作，只补未完成的阶段；已经提交的属性、理智、线索和手稿不重复结算。若插件在返回输出前被取消，恢复时可重新启动纯代码沙箱，宿主掷骰仍使用原记录。旧版只有完成标记、未保存待结算输出的情况，无法据此可靠补回缺失效果。

NPC 的每次回应（被问话、抢先开口、出发前交谈、主动参与、登台表演）在显示之前，连同说出的线索存入本回合的记录（`Turn.replies`），之后分别记下台词是否已显示、线索是否已入账；线索附带的理智检定随结算阶段一起保存。中断后从这份记录继续，不重新请 NPC 回应，已掷的骰不重掷。旧版回合记录没有这份凭据，已经说出但尚未入账的线索无法补回。

## AI 排查

只有点击 **提交排查** 才调用模型。可直接填写问题、指定起止回合，或在记录条目中选择“排查此记录”。系统优先检索问题涉及的回合、人物、物品和操作；网页列出实际提交的记录游标与筛选范围。长字段和过大的资料会明确标记截断，完整原始记录始终保留。

排查使用独立会话，核对玩家输入、行动解析、裁定、NPC 回应、位置、计划、导演提交与叙述。它不能修改世界、角色记忆或存档；对历史回合只使用相应历史证据，不以当前状态代替过去状态。资料不足时必须说明缺失部分。

排查默认使用导演模型，也可单独配置：

```toml
[roles.diagnostic]
backend = "langchain"
model = "deepseek:deepseek-flash"
effort = "low"
```

用量单独记在本局 `diagnostic` 项下。浏览、自动刷新、检索和下载记录均不调用模型。重复提交会等待当前排查结束；关闭浏览器不取消进行中的排查，关闭本局才结束其请求。

## 本地访问与分享

服务仅监听 `127.0.0.1` 的随机端口，地址带独立访问令牌；拒绝其他网页的跨站请求，不接入联机房间或公开展示站。联机访客不能读取房主的隐藏资料。退出本局时关闭网页服务，完整记录继续保留。

记录文件使用本机私有权限，自动过滤常见凭据字段、环境变量中的 API 密钥和授权字符串，同时保留剧情秘密。导出文件也含玩家资料、隐藏设定与模型上下文，分享时按实际需要选择内容。
