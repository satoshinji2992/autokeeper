# 网页字体

Fusion Pixel 12px Monospaced（简体中文），上游版本 `2026.10.16`。

- 项目与作者：[TakWolf/fusion-pixel-font](https://github.com/TakWolf/fusion-pixel-font)
- 来源：[官方发布包](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.10.16)
- 文件：`fusion-pixel-12px-monospaced-zh_hans.otf.woff2`，未修改字体内容，仅简化文件名。
- 授权：SIL Open Font License 1.1，全文见 `OFL.txt`；上游附带的字源许可证保存在 `LICENSES/`。

字体由本站提供，无须请求外部字体服务。Canvas 在字体加载后重新计算字符网格，加载失败时使用系统等宽字体。
