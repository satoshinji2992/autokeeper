## 对项目的启发

以下是从样本提出的项目设计，不是对原团自由度或主持质量的完整评价。

**开场可从玩家自己的目标获得动力。** 导演读背景时，应区分共同来意与个人在意的事。名誉、职业、收入、关系等可以影响选择，但不能擅自给调查员添加嫉妒、内疚或背叛倾向。玩家愿意展开时，交谈有空间；玩家明确赶路时，不强制演完一段人物冲突。

**先确定检定在解决什么不确定性。** 动作失败、环境失效、信息不足是不同结果。裁定员应先明确目标和风险，守秘人照结果呈现，避免把所有失败都写成角色笨拙。样本中的具体骰种与损失不能直接成为项目规则。

**调查需要可验证的差异。** 玩家提出假说后，可通过原有记录、物件、证人或地点检查。回应应说明这次行动实际确认了什么，保留仍然未知的部分；不能用反复的模糊预兆代替结果，也不能因玩家猜测就直接改写已知事实。

**NPC 的目标要能改变现场。** 除了记住自己想什么，还要能察觉变化、选择具体行动，并留下可结算的结果。台词中说要修门，与门已经修好是两件事。后者必须经过权限和状态结算，叙述不能先替世界完成。NPC 受威胁、受阻或失去资源后，也应重新选择，而非维持原定演出。

**同时发生的事应共享时间和因果。** 一人拖住对手、另一人处理物件时，应先确认各自意图及相互影响，再处理结果。不能只因程序按顺序输出，就假定另一处冲突暂停；也不能把同一时间窗里的并行行动重复累计成两段耗时。这是待验证的实现要求。

**结局中的角色变化留给玩家。** 系统可以回顾付出的代价、失去的人、兑现的约定和改变的局势；调查员是否后悔、成长或原谅别人，应由玩家表达。NPC 的态度变化则需要自身目标、记忆与实际遭遇的依据。

## 与欧美主持资料对照

Justin Alexander 的 [Don’t Prep Plots](https://thealexandrian.net/wordpress/4147/roleplaying-games/dont-prep-plots)建议准备局势、对手目标与可用资源，依照玩家介入作出反应，避免预定玩家行动顺序。这与项目的世界记录和 NPC 计划方向相合，但文章是方法论，不能证明当前实现已经有效。

因此，导演方案值得优先检查的是：谁想改变什么、有哪些手段、什么条件使行动发生、玩家介入后哪些安排失效。戏剧效果由后果和选择积累，不以连续触发事件作为唯一指标。

另保留两个英语圈候选：

- **The Apocalypse Players**：可对照同一 UNLAND 的另一种处理。其制作方在[公开介绍](https://www.chaosium.com/blogsignificant-streams-8-the-apocalypse-players/)中说明，有时会预写序幕与尾声，分析时须和桌上决策分开。当前只查阅制作说明，尚未分析该桌音频。
- **Pretending to be People**：主持人在[自述](https://www.reddit.com/r/DeltaGreenRPG/comments/14nag97/)中介绍了原创长篇战役与多组游玩经历。列为持续世界和长线关系的后续样本；目前只读创作者说明，不声称已研究整季。

## 对照 0.0.3 的验收用例

以下均用自编场景验证，不复刻 UNLAND 的人物、谜底和特殊规则。本轮未执行模型试玩；已有测试通过也不等于这些体验要求已通过。

| 自编情境 | 应观察的状态与行为 |
| --- | --- |
| 玩家弄坏店门后继续向店主问路 | 店主可注意到损坏并处理自身事务；门的变化必须实际结算，不能只有台词 |
| NPC 的计划依赖一件物品，玩家将其带走 | 旧计划的前提失效；人物只能根据自己获知的信息改计划，不能全知追踪 |
| 玩家以两种手段检查同一假说 | 回应各自实际可见的证据；明确已确认与未知，不反复制造同一种疑点 |
| 专业攀登者尝试通过腐朽设施 | 明确检定对象，失败后不无故否定角色已经完成的动作或追加损失 |
| 两位调查员同时交涉和搬动物件 | 共享现场变化与时间窗，按可感知范围提供信息，不机械串成两段独立耗时 |
| 重要 NPC 与调查员同受威胁 | 按能力、位置、动机及规则处理，NPC 不因承担剧情功能而自动免于后果 |
| 玩家花费资源救人但没有表达内疚 | 记录救援、资源和关系事实；叙述不替玩家宣告心理成长 |

`world/record.py` 已有目标、资源、计划和前提版本等数据；在场人物的行动如何提交、并行意图如何结算、过时计划如何撤销，仍需结合具体路径验证。这个研究阶段先保留可复核的要求，不据少量片段继续叠加通用提示词。
