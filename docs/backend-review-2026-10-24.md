# 后端格式错误与多人状态边界审查

审查基线为 `codex/multiplayer-live-audit` 的 `7997ca4`。本轮修改只保存在开发工作区；没有发布、覆盖运行中的安装或修改真实存档。

重点检查模型回复的解析、修复、记忆与用量链路，以及世界记录到个人投递、分场时间、理智恢复的边界。全量回归覆盖整个仓库，不等同于已逐项人工审计所有规则、插件或部署方式。

## 本次报错究竟发生在哪里

用户运行的安装版为 0.0.5.5。《冬雪之下》10 月 24 日 14:43 的完整记录显示：玩家询问达维尔家的姑娘并要求查看字条，行动裁定、时间和多琳的对话已经完成；随后弗朗西斯的配音调用先返回空白，格式修复得到完整对话，但媒体字段为 `media[0].to = "card-95e624"`。

接口只接受角色 ID 列表，因此在 `Dialogue` 校验处失败。这次不是 JSON 语法错误，也不是玩家输入格式不对。手动重试后重新生成的 NPC 回复改变了内容，不能据此认定此前的完整回复已经兑现。

现已允许媒体收件人使用单个非空 ID，统一转成列表。空字符串、空列表和不存在的角色仍不能投递，不会被降格为公开发送。不删除回复中的世界操作、私人投递或线索收据，也不把后台 JSON 当作正文展示。

## 已修复的共同机制

### 草稿与正式记忆

模型适配层原本允许修复后仍不完整的字典交由领域层处理；这是场面恢复所需的行为，但这些草稿此前也会进入会话记忆。现在回复明确携带校验问题，未通过格式校验的草稿不入记忆。领域重写只丢弃本次确实保存的回复，不会误删上一轮已经接受的交流。

### 失败调用与用量

失败请求的已知用量会进入全局追踪，却可能漏出本局的按角色统计。现在失败、备用模型切换及其成功结果分别记账；不虚构提供方没有返回的 token 数量。错误追踪保留校验问题，便于区分空回复、字段错误和世界操作未成立。

### 世界事实与个人见闻

复现了另一份审阅指出的 NPC 泄露：曾见过的人暗中移动或死亡后，真实新位置和状态仍被复制给玩家。现按个人最后目击投递地点、状态及外观字段；秘密变化不更新旧目击，亲眼看到的死亡正常更新。房主本地地图也使用个人目击，避免只修网络而留下另一条显示路径。这里保存的是头像资源 ID，图片内容的版本仍存在下述独立缺口。

未初始化世界记录的独立界面样例仍可使用静态模组资料；实际游玩一旦建立世界记录，不能用静态位置补回未知的动态状态。

### 时间请求的失败与拒绝

时间衔接异常此前残留“已经询问”，同一等待不再发起请求。现在临时失败最多重试两次，持续失败明确提示可提交行动或跳过，并限制同一状态继续自动调用。错误不等于允许时间流逝，明确拒绝也不会被当成服务故障反复请求。新声明可以解除失败标记。

### 场景日期与个人规则状态

复现了分队先后跨日导致全队当日 SAN 损失重置两遍的问题。现将最近初始化的游戏日随调查员保存，按个人时间幂等处理。第一次跨日后的 SAN 损失不会在另一场景跨日时消失，跨日后的首次理智结算也会先初始化当天计数。

相邻检查还确认，疯狂恢复此前可能跟随别处较快的时钟提前发生；现依据各自的时间与休息区间恢复。

## 尚需处理或进一步验证

- **[P1] 头像资源版本仍可能泄露秘密变化。** `Game._people()` 会为后台状态变化登记重绘；`Visuals._show()` 在原资源 ID 下替换图片。`Hub._share_book()` 又按玩家已经知道的 ID 发送当前资源，而不是当时看到的版本。离线替代重绘探针确认：秘密移动并死亡后，人物资料已隐藏死亡状态，但在原头像 ID 下填入的新字符图仍被发给原玩家。本轮未调用模型生成实际死亡画像；验证的是资源更新通路。应当让动态媒体使用独立版本，并随个人观察保存和恢复，不只冻结一个可被覆盖的 ID。人物字段修复不能视为完整的图片隔离。
- **物品的既有知识可能消失。** 补充探针确认：调查员公开经手皮箱、再交回 NPC 后，NPC 私下转交另一玩家，原调查员收到的物品列表会失去该皮箱。`Transfer` 更新当前归属的观察者，`known_items()` 又把它当作全部历史知识。这不会直接公开新持有者，但会使未被观察到的变化改写玩家旧知识。需要区分“知道物品存在”和“最后知道的归属／状态”，不能简单保留旧观察者后继续投递真实新归属。本轮未修改该结构。
- **空座身份仍基于朋友局互信。** 领取角色即取得其私人信息，没有永久绑定原玩家的身份凭据。房间访问控制、席位恢复凭据和明确转交属于另一项完整功能；本轮没有将其包装成已经完成的安全隔离。
- **裁定员仍能读到引述。** `speech`、`precautions` 可保留玩家原话。已纠正文档和提示中的绝对隔离表述，并标明引述不能改变规则与权限；尚未进行真实模型的诱导对照，提示不能视为安全证明。
- **长局体验仍需真人验证。** 本轮没有调用付费模型，无法据此评价恐怖节奏、NPC 长期主动性或多人发言体验。

## 验证

新增回归位于 `tests/test_backend_boundaries.py`，覆盖实际空回复后的图片投递、无效收件人、记忆保留、失败与备用用量、引用边界、时间重试、秘密状态及个人跨日和疯狂恢复。原媒体测试改为先真正到现场，再断言可看到 NPC 受伤；不再把远程世界变化当作可见信息。

首次全量检查发现了个人日期字段的 schema／序列化不一致和依赖真实 NPC 状态的旧显示断言，修复后重新执行冻结全量检查：**3216 通过，13 跳过**，耗时 7 分 50 秒。跳过项均为本机未安装 PowerShell 的安装脚本测试。Ruff 与差异空白检查通过。

新增 16 项回归全部离线执行，没有付费模型调用。全量日志在 `dev/output/backend-review-2026-10-24/full-suite-final.txt`，定向编译、地图与边界组 91 项通过的日志在同目录 `focused-final.txt`。头像版本和物品知识的补充探针用于确认剩余缺陷，不计作修复验收；本轮也未将真实游玩存档重新执行一遍。
