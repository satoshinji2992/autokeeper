# 0.0.5 发布候选说明

2026-10-23。供最终合并、验收和 GitHub Release 使用；版本号与发布状态由主分支统一更新。

## 发布说明初稿

0.0.5 主要完善多人调查中的行动安排、个人信息与主持交接。玩家可以同场配合，也可以私下向守秘人说明意图；个人发现、材料与画面保留实际收件人，重连后恢复自己的记录。公共消息不会因为另一人的私人检定而失去原有可见性。

守秘人可以直接登记现场人物、落实同行和物品交接，并在同一次回应中安排图片、个人观察与 NPC 的目标变化。规则结算继续使用世界记录，不从叙述反推事实。战斗与追逐保留回合制，自由声明在前提变化后可以重新解释；执行、装备和所得属于实际行动者，不随画面焦点转给异地队友。

线索通过叙述、对话和分发材料呈现，F2 留给玩家笔记。内置模组的原图和字符画继续随游戏提供。安装脚本锁定正式发行版本；当 PyPI 尚未同步时，使用同一标签下的 GitHub 安装包。

分场执行的最终范围以合并后验收为准，不在此稿中宣称已经完成真实长局验证。

## 已完成的发布通路检查

- 从源码构建 wheel 和 sdist，再把 wheel 装入独立环境，从仓库外加载与编译三本模组；没有调用模型。
- wheel 中 290 个模组、共享技能及骰桥文件与源码逐字节一致。三本模组的原图、ASCII、图片说明和归属信息均保留。
- 三本模组的场景守秘人笔记均能进入运行简报；由 KP 执行的完整规则分别为 14、11、9 条。编译包包含人物、地点、事件和局面参考资料。
- 安装后的编译输出写入用户资料目录；安装包不携带导入原文、存档、生成技能或 `node_modules`。
- 原三平台 CI 均曾失败于同一输入焦点竞态。现已用延迟刷新复现并修复，保留原测试断言；最终平台结果仍须重新运行。

本轮核对的三本模组顺序为《追书人》《冬雪之下》《有些人油盐不进》。构建验证期间版本仍为 0.0.4；这验证打包通路，不代表 0.0.5 已发布。

## 最终发布步骤

1. 合入最终修复并统一版本号、变更记录和介绍。运行全量测试、Ruff、格式示例及三个平台的安装包检查。
2. 从待发布提交重新构建 wheel 和 sdist，生成 `SHA256SUMS`。将两个安装包与校验文件附在同一个 `v0.0.5` Release；默认安装依据正式 Release，不能只推标签。
3. 发布后确认默认安装与指定 `AUTOKEEPER_VERSION=0.0.5` 都得到该版本，完成仓库外初始化与三个模组检查。PyPI 可随后同步；不得用未锁定的主分支代替指定版本。

## 验收边界

离线检查能验证记录、身份引用、安装布局与恢复行为，不能证明编译补写完全忠于每本原作，也不能证明模型不会泄密、错述经历或拖慢节奏。完整历史人物状态与每条知识的获知时间尚不是任意时点快照。发布前另按已授权额度进行短段真实主持验收，保留调用与费用记录。
