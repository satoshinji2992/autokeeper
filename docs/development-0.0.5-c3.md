# 0.0.5-C3 实施记录

2026-10-22。接续 `4e633de`，实现个人呈现与 NPC 真实目标的通路，并修补普通检定继续结算。没有增加常驻智能体，没有调用付费模型或运行 AI 自动跑团。新版直接采用新状态与协议，不提供旧版迁移。

## 主持可以提交呈现指令

新增 `engine/presentation.py`。KP 同次输出 `media`，NPC 与导演复用同一投递方法。指令引用已经准备的地点图、人物像、图片或手稿，指定受众及展示槽位；空列表保持，`show` 展示，`clear` 撤下。原图与字符绘制沿用现有流程。

投递先保存资源快照与受众，再发送；公开模组不混入私人材料，重连只恢复相应座位的画面和材料。客户端投递编号与资源编号使用不透明标识，不包含主持侧的真实人物标识或文件路径。模型不可以通过资源指令读取任意路径或网址。私人手稿的经历归实际收件人，图片未就绪的原因进入主持简报。

已有的公开线索取得与手稿弹窗暂保留为原有路径的交代保障。新增私人呈现不调用公开取得流程，不会自动把材料写成全桌已知。图片生成仍通过已有导演与 Visuals，`media` 本身不启动额外生成链。

## 私信与个人知觉

新增 `/私信kp 内容`。联机从连接座位确定身份，原话与回复只投递本人，独立于公开 `/kp`。采用原 KP 模型的一次独立调用，不污染公共模型会话。它是场外沟通入口，不执行秘密检定、移动或伤害。NPC 出发前私下回应的日志、事件与材料也使用回应收据里的受众。

新增持久个人知觉。KP 可按观察者设置实体的主观称呼、画像、阵营与可见性，或恢复原状。战斗按本人提供目标按钮与句柄；服务器将句柄转回原实体。甲攻击眼中的怪物，真实乙掉血并能正常应对；不会创建另一具怪物身体。

普通安排、整批安排与遭遇安排都向 KP 提供个人知觉映射，自由输入继续由模型理解。每个 AI 调查员分别组装自己的上下文，观战者不接收个人选单、私信或私人画像。确定性称呼和反馈按座位投影；玩家原话、书信和自由叙述不作全局字符替换，KP 根据完整资料通过个人叙述交代不同所见。

日志保留当时的呈现。解除幻觉不倒改历史，新幻觉也不重写昨天。公共压缩与进展排除存在个人差异的条目，差异原记录及其当时呈现进入持久归档，各人后续仍读到自己收到的版本。原有的合法旧记忆保留；没有为每人新增一次摘要模型调用。

## NPC 目标与即兴遭遇

`Dialogue.intentions` 可提交真实目标、新待办与原因，复用 `Enlist`／`SetPlan` 批量落实。未完旧计划保留撤回原因，显式空列表可以撤销；单纯承诺或谎言不自动改变真实目标。当前目标及来源进入 NPC、KP 与导演上下文。普通人物只增加被动记录，不增加模型工作者。

移除重要人物最多六份记录的限制。补齐导演新增人物的数值、攻击与未知身份称呼，以及事件的出场人物、战斗、追逐、突袭、胜负后果与恐怖照面；新地点保留规则、路程和追逐路线。全部复用现有模组与遭遇引擎，读档时重放本局的准备资料，不改磁盘上的原模组。

移除导演整局只能新增三张大场景的截断。图像生成的费用与尝试设置没有被关闭。

## 普通检定继续结算

没有直接线索奖励的普通检定也可选择孤注一掷或使用足够的幸运。待决记录保留原行动与完整成功裁定，成功后统一落实标记、物品转交、装备、日常物件、汇合、通路与插件动作。不重复原行动耗时、自动发现或已执行插件。

选择结算沿原有分段收据恢复。幸运扣除后断线，恢复不会再付款，也不会因为余额已减少拒绝继续；不合法的调查员、现场和选择仍会被拒。界面只提示实际可选项，不再把普通开锁成功统一写成“没有新的发现”。

## 验证与边界

定向测试使用脚本模型、预设骰和临时目录，覆盖真实 Cast 输出解析、Hub 按座位回包、真实目标受伤、材料与画像恢复、目标改变后继续执行、即兴战斗／追逐，以及普通行动继续结算。

北京时间 2026-10-23 完成最终验收：全量 **2,076 项通过**，耗时 380.83 秒；Ruff、差异检查及格式样例校验通过。样例有两条既有提示，无错误。四条 multiprocessing fork 弃用提示与先前一致。

首轮整合验收暴露三项问题，修复后重新跑完全套：联机带卡的单图字符串被误当作批图字典，导致连接断开；图片逐座发送后的旧测试没有模拟接收端；普通无知觉覆盖的战斗仍携带多余内部身份模板。新增回归覆盖三种当前图片消息、实际接收顺序，以及解除覆盖后的普通战斗事件。未展示的媒体或知觉操作也会反馈给 KP，采用修正后清除过时问题。

尚未完成：完整秘密物理行动及个人检定／地图发现、独立分场时间与主持会话、浏览器笔记持久化。通用角色行动输入仍有公开路径，不能把在普通输入中写“低声说”视作端到端私密通道。导演尚无直接新增完整 Creature 类型的接口，不能声称任意神话特性的怪物都能自动完善。自由叙述是否正确使用个人所见仍需真实模型定向复核。

本轮增加了必要的可选输出结构，没有新增普通回合的审批调用；私信只在实际发信时调用。结构体增量与真实计费不同，尚未作同模型同模组的实时 token／费用 A/B 对比，不承诺这一批功能会继续降低账单。
