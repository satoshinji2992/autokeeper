# 直到我们灰飞烟灭（tillwevanish）笔记

## 基本（p2, 0-487）
- 1939-02-11，德国埃森。调查员=帝国保安处（SD）国内安全人员，从柏林派来，确保新董事长沃德蒙特可靠、打好关系。原生 CoC7。
- 作者 逐日之蛆；黑色幽默猎奇邪典。

## 真相（p3-4, 540-2654）
- 阿克塞尔前妻约兰（犹太人，难产死）→长子沃德蒙特半犹太血统，被当局掩盖；沃德蒙特曾左派、布尔什维克同情者，34年入党，仍不被信任。沃德蒙特确是苏联间谍。
- 真正危险：小儿子艾伯哈德，狂热纳粹+克图格亚邪教徒，同性恋，愿意"当个女人"；想无差别烧死所有人，净化欧洲。
- 与总工程师塞格利·普拉斯特用《马克西米利安的炼金指南》法术：武器刻两条咒文（熔铸之血+生命薪柴），命中者生命力→MP 激活熔铸之血，之后使用者和被命中者都被克图格亚火焰烧成灰。
- 塞格利在多条产线加装冲压模具；手枪咒文刻在握柄两面，解释为防滑美观。熔铸之血需数天生效。
- 集中营军官谢尔曼杀囚犯后被自己武器烧死；其配枪回收后重新发给调查员（已激活）。
- 测试：怂恿希特勒青年团瓦尔德玛用样枪杀犹太邻居韦伯，几天后瓦尔德玛和韦伯坟墓同时自燃。此前艾伯哈德杀六人（三犹太、三金发德男），三个德男头砍下收藏，身体与犹太人扔焚化炉；其中一名是调查德男失踪案的盖世太保兰伯特。
- 守灵期间艾伯哈德挖出约兰骨灰撒进阿克塞尔棺材，对阿克塞尔尸体施熔铸之血；对沃德蒙特施法让他自燃。

## 典籍法术（p4-5, 3000-4581）
- 《马克西米利安的炼金指南》拉丁文，西蒙·沃伦斯坦，15世纪。SAN 3d10，神话 +7/+15%，神话等级60，学时108周。
- 生命薪柴：消耗与所得MP成正比HP（比例取决武器材质；锻造武器无消耗）；精炼金属匕首刻咒文，致生物流血吸取生命力储存。
- 熔铸之血：(5MP+1d4SAN)/L，24h/L；血浸骨质器具，血燃烧，骨→赤钢（银白色光滑金属）；两种咒文形式；赤钢是召唤克图格亚关键材料。
- 材料变温：按毫升 MP，金属/热塑性材料局部加热降温。
- 手写批注 A.H.（艾伯哈德）/S.P.（塞格利）：只对哺乳动物有效（鸡测试失败）；子弹算枪支一部分；枪托钝击也有效但效率一般；须血肉与骨接触；骨多于血则余骨成杂质；A.H. 想让元首回收战场尸体，"难道要我去勾引政府那群老东西"。（这些批注是典籍抄本里的手写批注 → 可作讲义）
