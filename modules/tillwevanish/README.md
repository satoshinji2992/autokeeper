# 直到我们灰飞烟灭

1939 年 2 月 11 日，阴雨。你是帝国保安处负责国内安全的人员，从柏林被派到埃森。
德国军方的武器供应商赫施伯格钢铁厂的董事长阿克塞尔·冯·赫施伯格刚刚去世，按遗嘱由大儿子沃德蒙特继承家业。
沃德蒙特早年参与左派运动、同情布尔什维克，虽然 1934 年入了党，当局仍不信任他。
你的任务是确保钢铁厂的新主人可靠、与他打好关系；当局并不打算让有共产党履历的人掌控这样的军工企业，
所以真正的任务是找到或制造沃德蒙特的把柄，并通过看上去合法的手续扳倒他。
小儿子艾伯哈德在官方眼中只是个脑子有问题的性变态，档案里甚至有他与一名身份不明的男人亲热的照片，预计相当好控制。
上级已提前通知钢铁厂你的到来。你带着出发前在柏林领到的配枪（握柄上刻着奇怪的花纹）乘火车抵达埃森，刚好赶上老董事长的葬礼。

来源：《直到我们灰飞烟灭》，作者 逐日之蛆，插画 mhs@jkit
