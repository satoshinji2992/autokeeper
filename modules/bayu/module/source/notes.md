# 鲅鱼？鲅鱼！ 笔记（原文 source.md 字符位置）
- 规则 CoC7；2025 春；烟台芝罘湾；2-5人，可用旧卡；无预设调查员 → 补两名。无车卡规则 → 不写 creation。
- 真相 430-1518：格拉基碎片沉睡黄海海沟；蜃气=精神能量幻象；感染者被感召去母体处，跳海几日内异变成“海和尚”。月全食后活跃。老张（张福海）幼年随父遇蜃气，不自知感染者。父亲几年前出海失踪=已成海和尚（8000附近）。
- 老张属性：力65 体70 型60 敏50 智55 意40 外45 教40 HP13 DB+1d4；驾驶(小型船舶)65 自然学50 聆听60 导航45 侦查50 机械维修40 游泳60 斗殴40。

## 地点
1. 码头 1528：凌晨4:30集合。侦查找船；打电话船长说十多分钟到，让先上船坐、吃东西。4:40左右老张到达（或侦查成功找到船）。
2. 早餐铺 2069：花头巾大姨，情报4条（鲅鱼肥/天变快；月全食龙王脾气不顺；远海见海市红房子红灯笼，游客听见姑娘唱歌（问怪事才说）；宁可信其有，见不对就返航）。
3. 渔具铺 2547：旱烟老头，红布陶罐沙蚕（胆小者可 sc0/1 可选）。购物送线香+台词；点三炷香令海和尚暂停一轮（仅一次）。追问海和尚：龙王使者巡逻……
4. 船 3046：驾驶室（短波电台：电子学/知识/物理，失败问老张也得；木雕小像：侦查或艺术手艺(雕刻)→盘坐光头面目模糊，老张说祖传海神；窗角黄纸符：侦查，已无用）。船尾甲板（卡式炉锅：问老张；船舷：侦查→旧爪形深划痕，老张脸色微变搪塞；他记不清）。
5. 近海 4400：开船约20分钟停。晕船检定 体质，渔民背景奖励骰；失败惩罚骰直到好转；大失败吐。
 - 日出 5:40：紫烟，全员侦查。成功：黑色森林剪影 sc0/1d3；大成功：再闻低语 sc1/1d4；失败只觉雾怪。老张“是海市啊”。此时老张烙印唤醒。
 - 垂钓：幸运→力量或投掷对抗鱼（鲅鱼25/鲈40/鲅鱼王60大成功/事件5 75）；钓鱼事件表1-6（5=渔网+长命锁抓痕）。
 - 鱼汤：老张讲经历（爷爷大雾三炷香水声消失；海和尚巡海习性不定；红色珊瑚树林海市；父亲失踪猜海流）。
6. 前往远海 8089：约9:00，船底撞击，站立者体质，失败摔倒1点伤害。侦查见巨大黑影。电台“鱼…好大的鱼…鲨鱼”；聆听听到水下咕嘟声。老张兴奋去礁石滩；见过幻象的调查员产生渴望。
7. 礁石滩 8819：20分钟到。可登礁石休息（晕过船者下次晕船检定额外奖励骰）。礁石光滑无附着；侦查→半只亮黄塑胶手套断口撕裂；海水极冷。
 - 约15分钟后大鱼上钩；拉不动；老张狂饮水；侦查见嘴唇干裂仍干渴；见过幻象者 sc0/1 失败极渴。老张撒拖网，力量对抗后船倾斜，海和尚现身，全员 sc1/1d6。
 - 逃生 9931：4-5轮内未切断绳索并启动渔船则船沉。①老张干扰：力量/敏捷对抗制服，须限制；推入海中→沉下注视，暂不再干扰。②3处绳（两舷挂钩、船尾固定栓），需锋利工具，船上行动敏捷检定。③1-3只海和尚爬上，伤害>5即跳回海中。④2处绳断后可驾驶检定启动，每2次检定耗一轮，成功绞断余绳冲出。香或扔佛像各令海和尚停一轮，各一次。
 - 海和尚：力75 体75 型65 敏50(水下75) 智20 意50 外5 HP13 MP10 护甲2 DB+1d4；斗殴45% 1d4+DB；抓取/拖拽50%，成功下轮力量对抗拖入水。
8. 返航 11121：油门推到底，体质失败颠簸呕吐；回望无数光头注视。
## 结局 11451
- 调查员与老张都幸存：老张大病失忆、退佣金、怕海；+1d6 san。
- 仅调查员幸存：+1d2；受蜃气影响者后遗症（靠近海想去远海）。
- 调查员落水：不死，转化为海和尚，数值同海和尚。
- 提前回航 11912：kp可考虑途中海和尚袭击；老张不异变不干扰。
