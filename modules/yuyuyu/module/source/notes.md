# 笔记：石头屿（yuyuyu）原文 0-8000

## 基本
- 规则：COC 7th + 原创小学生调查员规则（p15，"关键玩具""小个子""不被当回事"）；调查员均10岁小学生。原型福建厦门，00/10年代风貌。闽南语小标题。
- 背景(p4)：混血深潜者散居石头屿；石坡尾避风坞清淤，两月前公告一个月内清退渔船；施工在排洪箱涵地下排水通道发现遗忘闸门，通往深潜者定居所；闸门放入倒灌海水和"别的东西"（古老实存），随潮穿闸门。8月8日凌晨2点台风风暴潮前所未有倒灌，不在涨潮前封堵则城市地下水/淡水不可逆污染。阮施宁（深潜者混血儿）昨夜月亮升过废弃船厂烟囱时独自走进排水通道。
- p5：人类感染：耳道粘稠物、肺积液、胸闷呼吸困难，恶化出现肉色鳃状裂口，最后异变不可逆，数小时内死亡。混血居民两派（向往深海/坚称自己是人）。
- 转变规则(p5)：守秘人事先不让调查员知道自己有稀薄血统；接触喷泉、井水、潮湿地下水道、任何食物与水源时体质检定，失败+1级转变；征兆如皮肤长时间湿润；转变3级开始听到大海呼唤；开始转变的调查员最后收到阮施宁邀请回到海中。→需插件计转变级。
